# Recreation scope

Afterglow recreates core workflows with original content. It is not a bit-for-bit clone, a clinically validated replacement, or a complete implementation of Lumenate's commercial ecosystem. Source access and device verification limits matter here.

| Area | Lumenate, from official public sources | Afterglow implementation |
| --- | --- | --- |
| Session library | Curated commercial guided experiences, music and themed releases | Original presets across calm, focus, sleep and reflection; four procedural ambient beds and short written guidance. No copied narration or music. |
| Light method | White torch flicker through closed eyes; complete session sequences are not disclosed | Separate original bounded experimental sequence in Debug only, explicit opt-in each session, no equivalence or clinical claims. Release light is disabled. Physical output remains unverified. |
| Preparation | Environment guidance, onboarding screening and intention setting | Session preparation, duration/sound selection, optional intention, and per-session light risk acknowledgement. The checklist is not medical clearance. |
| Playback | Audio and light, pause controls, motion detection and other product controls | Native audio, session timer, pause/resume/end, torch shutdown for relevant lifecycle events, and system media controls for app audio. No claim of identical timing, motion detection or control layout. |
| Favourites | Saved favourite sessions | Saved locally, with a favourites library filter. |
| Journeys | Up to five sessions, with seamless transitions and session controls | Saved ordered queue of up to five original presets, automatic sequential playback, default durations and soundscapes, final reflection. Audio only. Transitions and background behavior require Mac/device validation. |
| Own soundtrack | Light-only mode used with the user's own music | External-music mixing option; app sound is muted while the timer and optional light run. User starts music in another app; there is no streaming-service control. |
| Journal and integration | Personal journal and Guide-related integration features | Local intention/reflection/mood notes, editing, deletion and text export. Session association is to the current or final journey session. |
| Offline | Downloadable sessions | All original sound is generated on device; no content download or network connection is required. |
| AI Guide | OpenAI-powered beta guidance and recommendations | Not implemented. No API key, chat service, cloud inference or personal-data transfer. |
| Nova hardware | BLE mask, firmware updates, group sessions and hardware-specific sequences | Not implemented. No compatible hardware or public protocol was available for validation. |
| Monetization and accounts | Trials, subscriptions, billing, account lifecycle, privacy processors | Not implemented. Personal standalone app, no login, paywall, analytics or advertising. |
| Distribution | Signed App Store product | Transferable Xcode source package. Personal Team installation available after Mac build; no signed IPA, TestFlight invitation or App Store release yet. |

See the [product research](research/product.md) for citations and an explicit list of information that could not be verified. See [build status](BUILD-STATUS.md) for the evidence behind implementation and test claims.
